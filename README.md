PlaylistMaker 🎵

PlaylistMaker – это приложение для поиска песен через Apple Music API, создания персональных плейлистов и их удобного шаринга через мессенджеры.

🚀 Основные возможности

🔍 Поиск песен по названию и исполнителю
🎧 Прослушивание демо-отрывков
❤️ Добавление песен в избранное
📂 Создание и редактирование плейлистов
🔗 Делитесь плейлистами через мессенджеры
🗑 Удаление песен из плейлиста с помощью удержания
🎛 Используемые технологии

Язык: Kotlin
API: Apple Music API
Архитектура: MVVM
Асинхронность: Coroutines, Flow
База данных: Room
Инструменты: Retrofit, Glide
